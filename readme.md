# Приложение для анализа транзакций

## Описание проекта
Приложение предназначено для анализа финансовых транзакций из Excel‑файлов. Основные функции:
генерация JSON‑данных для веб‑страниц;
формирование Excel‑отчётов;
предоставление сервисов аналитики (кешбэк, инвесткопилка, поиск транзакций и др.).

## Структура проекта
project/
├── src/                  # Основной код приложения
│   ├── views.py          # Функции для веб‑страниц («Главная», «События»)
│   ├── utils.py          # Вспомогательные функции
│   ├── services.py       # Сервисы аналитики
│   └── reports.py        # Функции отчётов
├── tests/                # Тестовые сценарии
├── .env                  # Переменные окружения (ключи API и др.)
├── .gitignore            # Список игнорируемых файлов
├── pyproject.toml        # Конфигурация Poetry и инструментов (black, isort, mypy, flake8)
├── .flake8               # Конфигурация flake8
└── README.md             # Данный файл

## Установка и запуск
Клонируйте репозиторий:

bash
git clone <url-репозитория>
cd project
Установите зависимости:

bash
poetry install
Настройте переменные окружения:

Создайте файл .env на основе шаблона (см. ниже).

Укажите ключи API, пути к файлам и другие параметры.

Запустите приложение:

bash
python src/main.py
Примечание: main.py — модуль, объединяющий все функциональности (создайте его, если отсутствует).

## Конфигурация окружения
Шаблон .env
env
API_KEY=your_api_key_here

JSON_OUTPUT_PATH=output/data.json
LOG_LEVEL=INFO
Требования к окружению
Python 3.12+

## Использование
Веб‑страницы
«Главная»

Вход: строка с датой и временем (YYYY-MM-DD HH:MM:SS).

Выход: JSON‑ответ с обобщёнными данными.

Модуль: src/views.py.

«События»

Вход: DataFrame с транзакциями.

Выход: JSON‑ответ с детализацией событий.

Модуль: src/views.py.

Сервисы
«Выгодные категории повышенного кешбэка»

Вход: год, месяц, список транзакций (словари).

Выход: JSON с категориями и суммами кешбэка.

Модуль: src/services.py.

«Инвесткопилка»

Вход: месяц, лимит округления, список транзакций.

Выход: JSON с расчётами накоплений.

Модуль: src/services.py.

«Простой поиск»

Вход: поисковый запрос, список транзакций.

Выход: JSON с найденными транзакциями.

Модуль: src/services.py.

«Поиск по телефонным номерам»

Вход: список транзакций.

Выход: JSON с транзакциями, содержащими номера телефонов.

Модуль: src/services.py.

«Поиск переводов физическим лицам»

Вход: список транзакций.

Выход: JSON с переводами физлицам.

Модуль: src/services.py.

Отчёты
«Траты по категории»

Вход: DataFrame, категория, дата (трёхмесячный период).

Выход: JSON с динамикой трат.

Модуль: src/reports.py.

«Траты по дням недели»

Вход: DataFrame, дата (по умолчанию — текущая).

Выход: JSON с распределением трат по дням.

Модуль: src/reports.py.

«Траты в рабочий/выходной день»

Вход: DataFrame, категория, дата (трёхмесячный период).

Выход: JSON с сравнением трат.

Модуль: src/reports.py.
